# Study THP-102 — protocol (synopsis)

*Fictional example for the kton recorder. Part of Project Theophylline. The data are simulated
from THP-101 with a fixed seed: the same subjects, fasted and fed.*

- **Design:** open-label, two-period crossover, single oral dose, fasted vs high-fat meal.
- **Data file:** `data/thp102_pk.csv`, one row per sample:
  `Subject, Wt, Dose, Period, Food, Time, conc`.
- **Question:** does food slow absorption (Ka) without changing exposure (AUC)?
