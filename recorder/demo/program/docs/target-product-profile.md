# Programme Respiratory — target product profile

*Fictional example for the kton recorder.*

| Attribute | Target | Minimum acceptable |
|---|---|---|
| Dosing | once daily | twice daily |
| Steady-state trough | 8 mg/L | 5 mg/L |
| Steady-state peak | below 15 mg/L | below 20 mg/L |
| Between-subject variability of clearance | below 30 % CV | below 45 % CV |
| Monitoring | none routinely | at start only |

Exposure is judged on the population model of each project, simulated at the planned doses.
