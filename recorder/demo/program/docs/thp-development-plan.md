# Project Theophylline — development plan

*Fictional example for the kton recorder. Part of Programme Respiratory.*

**Compound:** theophylline, a methylxanthine bronchodilator; narrow therapeutic range
(roughly 5–15 mg/L), clearance varies between patients.

## Studies

| Study | Design | Status |
|---|---|---|
| THP-101 | single oral dose, 12 healthy volunteers, rich sampling over 24 h | complete |
| THP-102 | single oral dose, fasted vs fed, crossover | complete |
| THP-201 | phase II dose finding | planned: dose from the population model |

## Analysis plan for the project

1. A population PK model from THP-101 (one compartment, first-order absorption).
2. Weight as covariate on clearance, if supported.
3. Simulated exposure at 100, 200 and 400 mg, compared with the target product profile.
4. THP-102 used to check the model in fed subjects.
