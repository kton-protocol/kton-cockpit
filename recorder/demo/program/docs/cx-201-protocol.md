# Study CX-201 — protocol (synopsis)

*Fictional example for the kton recorder. Part of Project Compound X. The data are R's
`datasets::Indometh` (Kwan et al., 1976), renamed as compound X. They are borrowed for the shape of the curve only:
indometacin is an NSAID and would not be developed for asthma (NSAID-exacerbated bronchospasm).*

- **Design:** single intravenous bolus, 6 subjects.
- **Sampling:** 11 samples from 0.25 to 8 h.
- **Data file:** `data/cx201_pk.csv`: `Subject, Time, conc`.
